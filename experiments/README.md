## 一份记录包含什么

- 来源笔记与要验证的假设。
- 固定的代码版本、模型、任务、配置与预算。
- 基线、单次主要改动和评价方式。
- 原始输出入口、失败、成本和结果。
- 能支持什么结论，仍然不能回答什么。

本地大文件可以放在 `experiments/artifacts/`，该目录默认不提交；在笔记中记录相对路径、获取方式或哈希即可。
