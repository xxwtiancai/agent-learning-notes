## 新增一篇论文

复制 [论文模板](../templates/paper-note.md)，文件命名为 `YYYY-short-title.md`，并在这里新增一行。文件名中的年份使用论文首次公开年份，正文单独记录实际阅读版本。

只收集链接时先标记 `queued`。有了阅读笔记再更新状态，涉及实验时关联到 [experiments](../experiments/README.md)。
